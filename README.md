# Desafio UnMEP - Análise de registros de tempo

Código desenvolvido em Node.js para análise de dados de funcionários de uma empresa.
É feito processamento dos dados com base em um arquivo *"data.json"* e ao final é gerado
um arquivo *"result.json"* com o resultado dessa análise.

## Requisitos

-Docker

## Execução

Para executar o código basta ter o Docker instalado e executar o  comando

    ```bash
    docker compose up --build
    ```

no diretório do projeto, o que irá gerar o arquivo *"result.json"* no mesmo diretório.
